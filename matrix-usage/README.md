# matrix-usage

Мод для Claude в стиле фильма «Матрица». Показывает над полем ввода:

- заполненность контекста;
- лимиты за 5 часов и за неделю, со временем сброса;
- примерную стоимость сессии.

Над и под цифрами бегут зелёные символы. Если лимит перевалил за 80%, его строка краснеет и всплывает уведомление «Wake up, Neo…». В строке статуса видна короткая сводка. Команда `/matrix` скрывает полосу и возвращает её.

## Установка

Положите эту папку в репозиторий на GitHub. Затем в терминальной сессии Claude Code выполните:

```
/plugin install matrix-usage --marketplace <owner>/<repo>
```

На вопрос о добавлении маркетплейса ответьте `y`, затем выберите область установки user.
